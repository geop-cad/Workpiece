# Axial fan

A turned hub and five twisted blades: one blade lofted from a root section to a tip section, each pitched at its own angle, and a circular feature pattern; a section shows the tip's pitch.

Run `python3 examples/axial_fan/axial_fan.py` to rebuild `axial_fan.wpc` (open it in Workpiece), or `python3 examples/build_all.py axial_fan` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
