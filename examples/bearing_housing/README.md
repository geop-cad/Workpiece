# Flanged bearing housing

A turned hub on a square flange: a revolved profile dimensioned by diameters about its drawn axis, counterbored holes for M8 cap screws in a circular pattern, fillets and a section through the bore.

Run `python3 examples/bearing_housing/bearing_housing.py` to rebuild `bearing_housing.shapecraft` (open it in ShapeCraft), or `python3 examples/build_all.py bearing_housing` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
