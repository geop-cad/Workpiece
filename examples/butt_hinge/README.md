# Butt hinge (assembly)

One brass leaf part placed twice, the second turned end for end so the knuckles interleave, a steel pin, and a revolute joint driven open to 110°; knuckles, reliefs and countersunk holes are each one feature and a pattern.

Run `python3 examples/butt_hinge/butt_hinge.py` to rebuild `butt_hinge.wpc` (open it in Workpiece), or `python3 examples/build_all.py butt_hinge` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
