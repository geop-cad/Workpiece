# Cast angle bracket

An L profile extruded both ways, a 2° casting draft, a rib and mounting slots each made once and mirrored, an H7 bore, and fillets on every inside corner.

Run `python3 examples/cast_bracket/cast_bracket.py` to rebuild `cast_bracket.workpiece` (open it in Workpiece), or `python3 examples/build_all.py cast_bracket` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
