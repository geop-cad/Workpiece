# Caster (assembly)

A shelled steel fork, a wheel of two bodies (aluminium hub, rubber tyre) each weighing by its own material, and an axle pin; the wheel turns on a revolute joint.

Run `python3 examples/caster/caster.py` to rebuild `caster.workpiece` (open it in Workpiece), or `python3 examples/build_all.py caster` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
