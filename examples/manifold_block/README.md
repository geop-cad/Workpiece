# Hydraulic manifold block

Drilled ports that meet inside an aluminium block: a spot-faced pressure port, a counterbored and a countersunk side port, four tapped M6 holes, and two sections that show the bores meet.

Run `python3 examples/manifold_block/manifold_block.py` to rebuild `manifold_block.shapecraft` (open it in ShapeCraft), or `python3 examples/build_all.py manifold_block` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
