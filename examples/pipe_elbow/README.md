# Flanged 90° pipe elbow

A tube swept along a bend, a flange with four bolt holes, and the flange with its holes mirrored onto the other end in the plane that halves the bend.

Run `python3 examples/pipe_elbow/pipe_elbow.py` to rebuild `pipe_elbow.shapecraft` (open it in ShapeCraft), or `python3 examples/build_all.py pipe_elbow` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
