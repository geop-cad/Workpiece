# Vented sheet-metal cover

Driven by named values you can change on the command line: a base with flanges and inward lips bent along its edges, a row of vent slots, mounting holes, and its flat pattern on a sheet of its own.

Run `python3 examples/sheet_metal_cover/sheet_metal_cover.py` to rebuild `sheet_metal_cover.shapecraft` (open it in ShapeCraft), or `python3 examples/build_all.py sheet_metal_cover` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well. Change it: `python3 examples/sheet_metal_cover/sheet_metal_cover.py LENGTH=200 SLOTS=9`.
