# Turned drive shaft

Six diameters on one revolved profile, chained lengths, an M16 cosmetic thread, a keyway cut down to a datum plane and shown in a section, chamfers and corner rounds; drawn at 2:1.

Run `python3 examples/turned_shaft/turned_shaft.py` to rebuild `turned_shaft.shapecraft` (open it in ShapeCraft), or `python3 examples/build_all.py turned_shaft` to refresh `drawing.pdf`, `drawing.svg`, `thumbnail.png` and `render.png` as well.
